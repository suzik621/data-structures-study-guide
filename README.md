# data-structures-study-guide

一个面向本科《数据结构》与《计算机系统基础》的 DSH skill：知识地图、复杂度分析、C/C++ 与 Linux 调试、Shell/缓存/虚拟内存等通用实验方法。

这是一个**公开去敏感版**：不包含某门课的具体作业答案、期望输出、截止日期、教师/班级信息或课程内部材料。

## 内容

- 数据结构：线性表、栈/队列、串与 KMP、树、图、查找、排序；
- 计算机系统：数据表示、汇编、处理器、Cache、链接、异常控制流、虚拟内存；
- 实验/作业通用流程：读规格 → 跑基线 → 最小版本 → 构造测试 → 对拍 → 定位 → 回归；
- C/C++ 调试清单与常见坑；
- 复习方法与学术规范提醒。

## 适用

- 复习数据结构/计算机系统基础；
- 做课程实验时卡在思路、编译、内存、输入输出、性能；
- 想让 AI 按“先定位、再改代码”的方式陪你排错。

**不适用**：直接要一份可提交的作业/实验答案。遇到这类请求，本 skill 只给思路、伪代码、测试方法和排错建议。

## 使用

把本仓库的 `SKILL.md` 放进 DSH 的 skills 目录，或按你使用的 agent 的 skill 加载方式导入。

## 版权与学术规范

本仓库为原创学习笔记，未复制教材、课程讲义、实验指导或测试数据的大段原文。课程实验的代码、测试数据与评分标准归课程/教师所有；请遵守学校学术诚信规定，提交代码应自己完成。
